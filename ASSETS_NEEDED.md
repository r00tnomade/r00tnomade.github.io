## How to replace an image

1. Export your image at (or above) the recommended resolution.
2. **Convert it to WebP** and save it under the exact same path and filename, overwriting the placeholder. The site only loads WebP/AVIF, so JPG/PNG files in `src/assets/images/` are ignored and never shipped.
   Quick conversion: `node -e "require('sharp')('in.jpg').resize(2400).webp({quality:86}).toFile('out.webp')"`
3. Done. Astro creates the responsive AVIF/WebP sizes on the next `npm run dev` or `npm run build`.

To adjust a crop without editing the image, set `position` on that image in `src/content/site.ts` (e.g. `position: 'center 30%'`).

`npm run placeholders` recreates missing placeholders and never overwrites an existing file unless you pass `--force`.

### About and Studies (no photographs)

These two cards are built in code, so they need no images. If you later get authentic photos, set `image` instead of `visual` on that entry in `about` in `src/content/site.ts`.

- **About:** "Hallo / Hello / Bonjour / مرحبا", the four languages on your CV, set straight onto the card above a hairline horizon with the hero's dusk light, in `src/components/visuals/Greeting.astro`.
- **Studies:** a square wave rebuilt from 1, 2, 4 and 12 sine waves (Fourier synthesis), drawn across the card and fading out before the text, in `src/components/visuals/Harmonics.astro`. The curves are computed at build time; the harmonic counts are at the top of the file.

### Photographic direction

The site works because the photography is restrained: muted colour, soft natural light, generous negative space and no visual clutter. Prefer one strong, quiet image over a busy one. Avoid stock imagery and AI-generated pictures of yourself.
